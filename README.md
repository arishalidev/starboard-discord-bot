# Sms Starboard Discord Bot (Discontinued)
Helping discord users capture memorable moments.

## How it works
Sms Starboard works by putting all messages that reach a number of reactions into a separate channel.<br>
This channel then becomes a gallery of what is most popular in the server, while also encouraging user engagment.
